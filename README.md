# مدير ملفات المعلم

تطبيق ويندوز (Python + PyQt6) لتنظيم ملفات المعلم: الأقسام ← المواد ← الملفات. الواجهة عربية بالكامل (RTL).

## المميزات
- اختيار المجلد الرئيسي (يتذكرو البرنامج في المرة الجاية).
- شجرة الأقسام والمواد والملفات.
- نقرتين على ملف (Word, PDF, Excel, صورة...) يفتحو بالبرنامج الافتراضي.
- بحث بالاسم في كل المجلدات مع نتائج مباشرة.
- "مذكرة جديدة" ذكية: تختار القسم والمادة وعنوان الدرس ورقم الأسبوع والتاريخ، وينسخ `template.docx` ويعمّر الكلمات المعلّمة (`{{المادة}}`...) في النص والجداول والرأس والتذييل. الشرح في [README_template.md](README_template.md).
- تحويل إلى PDF: كليك يمين على ملف `.docx` (أو حدد برشة ملفات بـ Ctrl/Shift) ← "تحويل إلى PDF". يستعمل Microsoft Word، وإذا ما لقاهش يجرّب LibreOffice.
- كليك يمين: فتح، إعادة تسمية، حذف (بتأكيد، ويمشي لسلة المحذوفات)، فتح مكان الملف.
- اختصارات: `F2` تسمية، `Delete` حذف، `F5` تحديث، `Ctrl+F` بحث، `Ctrl+N` مذكرة جديدة.
- "مولّد المذكرات (بلا إنترنت)": يستخرج نص صفحات الدرس من دليل المعلم وكتاب التلميذ، ويقسّم الدليل حسب العناوين، ويعمّر نموذج Word. (الشرح تحت)

## التشغيل
1. ثبّت Python 3.9 أو أحدث من python.org (حدد خانة "Add Python to PATH").
2. افتح PowerShell داخل مجلد المشروع ونفّذ:

```
pip install -r requirements.txt
python main.py
```

## هيكلة المجلد الرئيسي
```
المجلد الرئيسي/
├── template.docx        (اختياري هنا، يلقاه البرنامج بجنب main.py زادة)
├── القسم الأول/
│   ├── الرياضيات/
│   └── العلوم/
└── القسم الثاني/
    └── ...
```

ملف `template.docx` الموجود في المشروع نموذج فارغ؛ بدّلو بنموذجك الخاص.

## ملف exe (بلا Python)
- **من GitHub:** تبويب Actions ← "Build Windows exe" ← آخر تشغيل ← Artifacts ← `TeacherFileManager-exe` (أو "Run workflow" لتشغيلو يدويا).
- **على البيسي:** شغّل `build.bat` (يحتاج Python مرة وحدة للبناء)، والنتيجة في `dist\TeacherFileManager.exe`.

النموذج `template.docx` مدمج داخل exe، وإذا حطيت نسخة في المجلد الرئيسي تتقدّم عليه.

## مولّد المذكرات (بلا إنترنت)
زر **مولّد المذكرات** في الشريط العلوي. كل شي يخدم محليا بلا إنترنت وبلا أي API.

### هيكلة المكتبة
```
المكتبة/
  الرياضيات/
    guide.pdf        (دليل المعلم، فيه نص حقيقي)
    book.pdf         (كتاب التلميذ، فيه نص حقيقي)
    template.docx    (نموذج فيه {{الأهداف}} {{المراحل}} {{التقييم}} {{الكتاب}} ...)
    keywords.json    (يتكوّن وحدو أول مرة، وتنجم تعدّلو)
```

### الخطوات
1. اختار مجلد المكتبة (يتذكرو البرنامج) ثم المادة من القائمة.
2. اكتب عنوان الدرس ورقم الأسبوع والتاريخ، وحدد صفحات الدرس في الدليل وفي الكتاب (من - إلى).
3. اضغط **تحليل ومراجعة**. تظهر شاشة المراجعة: كل خانة في مربع قابل للتعديل، والنص الأصلي للدليل والكتاب في تبويبين جنبها.
4. الخانات اللي ما لقاهاش في الدليل تبقى فارغة ومعلّمة بالأصفر باش تعمّرها بيدك.
5. اضغط **حفظ**: يتكوّن `المادة - الدرس - أسبوع X.docx` في مجلد المادة.

### المراحل: أسماؤها في الدليل وفي الكتاب
البرنامج يعرف المراحل بأسمائها في **دليل المعلم** وفي **كتاب التلميذ**، ويجمّع كل مرحلة في خانة وحدة (نص الدليل، ثم تحت «كتاب التلميذ:» نص الكتاب):

| الكلمة المعلّمة في النموذج | في دليل المعلم | في كتاب التلميذ |
|---|---|---|
| `{{المكتسبات السابقة}}` | — | أتعهّد مكتسباتي السّابقة |
| `{{الوضعية المشكل}}` | الوضعيّة المشكل | ألاحظ وأتساءل |
| `{{تحليل الوضعية ورصد التصورات}}` | تحليل الوضعيّة ورصد التصوّرات | أفترض |
| `{{التحقق العلمي}}` | التحقّق العلمي + النّشاط الأوّل، الثّاني... | أجرّب وأتثبّت (التجارب) |
| `{{الاستنتاج}}` | الاستنتاج 1، الاستنتاج (2)... | أستنتج |
| `{{التطبيق والتوظيف}}` | التطبيق (1)، (2)... | أطبّق وأوظّف |
| `{{التقييم}}` | التّقييم | أقيّم تعلّمي الجديد |
| `{{التوسع والامتداد}}` | التوسّع والامتداد | — |
| `{{معجمي في العلوم}}` / `{{أتهيأ لتعلمي اللاحق}}` | — | معجمي في العلوم / أتهيّأ لتعلّمي اللاّحق |

وبطاقة الجذاذة: `{{الكفاية النهائية}}` `{{المكون الأول}}` `{{المكون الثاني}}` `{{الوحدة}}` `{{المفاهيم}}` `{{المحتوى}}` `{{الهدف}}` `{{المستلزمات}}` `{{الحواجز}}` `{{مؤشرات التجاوز}}` `{{مؤشرات القدرة المستهدفة}}`،
زيادة على `{{المادة}}` `{{الدرس}}` `{{الأسبوع}}` `{{التاريخ}}` و`{{الكتاب}}` (نص صفحات الكتاب كامل).

- العناوين المرقّمة (النّشاط الأوّل، الاستنتاج (2)، التطبيق (1)...) تبقى ظاهرة داخل الخانة، وكل واحد في فقرة.
- تحب نص مصدر واحد برك؟ استعمل `{{القسم - الدليل}}` أو `{{القسم - الكتاب}}`، مثلا `{{التحقق العلمي - الكتاب}}`.
- **نموذجك الخاص بلا كلمات معلّمة:** كان النموذج ما فيهش `{{...}}`، التطبيق يلقى خانات العناوين في الجداول («مكون الكفاية»، «الهدف المميز»، «المحتوى»، «تعهد المكتسبات»، «الوضعية الاستكشافية»، «رصد التصورات»، «بناء الفرضيات»، «التحقق العلمي»، «الاستنتاج»، «التعلم الآلي»، «التعلم الإدماجي»، «التقييم»...) ويكتب القسم في عمود «نشاط المدرس» كان موجود، وإلا في الخانة اللي بحذا العنوان. النص اللي كاتبو في الخانة يبقى، والجديد يتزاد تحتو. كي يكونو زوز عناوين لنفس القسم («رصد التصورات» و«بناء الفرضيات») الأول ياخو نص الدليل والثاني نص الكتاب.
- **نموذج جاهز:** `generator_template.docx` (جذاذة فيها بطاقة الدرس وجدول سير الحصّة بكل المراحل). انسخو لمجلد المادة باسم `template.docx` وبدّل فيه كيما تحب.
- بعد الحفظ يعلمك البرنامج إذا في النموذج كلمة معلّمة ما عندها خانة، أو قسم فيه نص وما عندوش مكان في النموذج.

### keywords.json
لكل قسم: الكلمات اللي تدل على عنوانو في الدليل وفي الكتاب. يتكوّن وحدو أول مرة، وتنجم تعدّلو:
```json
{
  "الوضعية المشكل": {"الدليل": ["الوضعية المشكل", "الوضعية المشكلة"], "الكتاب": ["ألاحظ وأتساءل"]},
  "الوحدة": {"الدليل": ["الوحدة"], "الكتاب": [], "قيمة_في_نفس_السطر": true},
  "عناوين_بدون_قسم": ["التمشي البيداغوجي", "جذاذة تنشيط"]
}
```
- اسم القسم هو الكلمة المعلّمة في النموذج. ما تستعملش الأسماء المحجوزة (المادة، الدرس، الأسبوع، التاريخ، الكتاب).
- المقارنة ما تهتمش بالهمزات والتشكيل والفراغات (`أجرّب و أتثبّت` = `أجرب وأتثبت`)، والأرقام والرموز قبل العنوان (`4`، `1-`، `–`) تتجاهل.
- `قيمة_في_نفس_السطر`: للعناوين اللي القيمة متاعها في نفس السطر، كيما «الوحدة : الهواء والتنفّس» أو خانة جدول «المفاهيم | الهواء».
- `عناوين_بدون_قسم`: عناوين تقفل القسم اللي قبلها بلا ما تبدا قسم جديد.
- زر **تعديل الكلمات المفتاحية** يفتح الملف، وزر **الكلمات الافتراضية** يرجّعو للأصل. إذا عندك `keywords.json` قديم من النسخة الأولى، يتبدّل وحدو.

### إذا النص العربي يطلع معكوس أو مقطّع
البرنامج يرتّب الكلمات حسب مواقعها في الصفحة، يلصق الحروف المقطّعة، ويصلّح الحروف المعكوسة تلقائيا. إذا بقى النص غلط، بدّل «معالجة اتجاه النص» (عكس حروف الكلمات، عكس ترتيب الكلمات، أو ترتيب PDF الأصلي) وعاود التحليل. تنجم زادة تصلّح النص بيدك في شاشة المراجعة.
- إذا الصفحات صور ممسوحة (Scan) ما فيها نص، التطبيق ما يقراهاش (ما فيهش OCR).

## نسخة الأندرويد (APK)
الكود في مجلد `android/` (مكتوب بـ Flet)، ويستعمل نفس المنطق المشترك `teacher_core.py` متاع نسخة ويندوز.

### التحميل والتثبيت
1. من GitHub: تبويب Actions ← "Build Android APK" ← آخر تشغيل ناجح ← Artifacts ← `TeacherFileManager-apk`.
2. فكّ الـ zip. فيه 3 ملفات حسب نوع المعالج: للتلفونات الحديثة استعمل `teacher-file-manager-arm64-v8a.apk` (إذا ما تثبّتش، جرّب `armeabi-v7a`). ابعثو للتلفون (كابل، Drive، تيليغرام...).
3. افتحو في التلفون. إذا طلب، اسمح بـ «تثبيت تطبيقات من مصادر غير معروفة» للتطبيق اللي فتحت منو الملف.
4. أول مرة تفتح التطبيق: الإعدادات ← «منح إذن الوصول للملفات» ← فعّل «السماح بإدارة كل الملفات» وارجع.
5. في الإعدادات اختار (أو اكتب) المجلد الرئيسي، مثلا `/storage/emulated/0/Documents/خدمة`، ومجلد المكتبة متاع مولّد المذكرات.

### تحديث التطبيق
- كل بناء جديد يتوقّع بنفس المفتاح ويحمل رقم نسخة أكبر، فالـ APK الجديد يتثبّت **فوق** القديم مباشرة (ملفاتك وإعداداتك تقعد).
- **مرة وحدة برك:** النسخ اللي تبنات قبل 2 أكتوبر 2026 كانت تتوقّع بمفتاح عشوائي، فلازم تنحّي التطبيق القديم من التلفون قبل ما تثبّت الجديد (ملفاتك في الذاكرة ما تتمسّش، لكن لازم تعاود تختار المجلدات في الإعدادات).
- إذا الأندرويد قال «التطبيق لم يتم تثبيته» أو «يتعارض مع حزمة موجودة»: المفتاح تبدّل (مثلا ما صار حتى بناء أكثر من 7 أيام وتمسح الـ cache). نحّي القديم وثبّت الجديد.
- باش يقعد المفتاح ثابت للأبد: حطو في GitHub ← Settings ← Secrets and variables ← Actions، كسرّين `ANDROID_KEYSTORE_B64` (ملف `.jks` بـ base64) و`ANDROID_KEYSTORE_PASSWORD`. الـ workflow يستعملهم وحدو كي يلقاهم.

### الفرق مع نسخة ويندوز
- الشجرة ولّات قائمة تدخل فيها مجلد بمجلد (القسم ← المادة ← الملفات) مع زر للرجوع للمجلد الأعلى.
- كليك يمين ولّى زر ⋮ جنب كل ملف: فتح، إعادة تسمية، حذف، فتح مكان الملف (في نتائج البحث).
- فتح الملفات يكون بالتطبيقات المثبتة في التلفون (Word، قارئ PDF، المعرض...). إذا ما فماش تطبيق افتراضي، الأندرويد يسألك بأي تطبيق تفتح.
- الحذف نهائي (ما فماش سلة محذوفات عامة في الأندرويد)، ويطلب تأكيد.
- «تحويل إلى PDF» موش موجود في الأندرويد (يحتاج Word أو LibreOffice على الكمبيوتر).
- الكلمات المفتاحية متاع المولّد تتعدّل من داخل التطبيق (الأيقونة جنب اختيار المادة).

### تجربة على الكمبيوتر
```
cd android/src
pip install "flet[all]==1.0.3" python-docx pymupdf
flet run main.py
```
